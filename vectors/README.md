# Golden test vectors

Byte-level ground truth for `spec/normative.md` §1–10 and the §11 EIP-712 digests
(`eip712.json`), plus the storage daemon's multi-declaration ingest transcript
(`ingest_transcript.json`, daemon test plan D1). Contract, circuit, daemon, and
reference-implementation tests all consume these same files.

- Generated by `scripts/gen_vectors.py` (dependency-free Python; self-validates its keccak
  against the Ethereum empty-hash and NIST SHA3 anchors before emitting anything).
- The Rust reference implementation, once written, becomes the authoritative generator and
  must reproduce every file **byte-for-byte**. A diff is a finding to investigate, never a
  regeneration.
- Never hand-edit a vector to make a test pass.
- Any change to normative §1–10 or §11 requires regenerating vectors in the same commit.
